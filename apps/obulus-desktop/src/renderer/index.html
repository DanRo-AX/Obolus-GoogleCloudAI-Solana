Claude, Pay.sh, MCP를 한 번 연결하면 모든 리서치 작업을 이 앱과 로컬 에이전트에서 실행할 수 있습니다.

01

Claude 에이전트

팀이 제공한 Claude API 키를 macOS Keychain으로 암호화해 이 기기에만 저장합니다. 렌더러와 MCP 출력에는 노출하지 않습니다.

02

Pay.sh 로컬 지갑

개인키는 Pay.sh가 OS 보안 저장소에서 관리합니다. Obulus 서버나 Claude로 전송되지 않습니다.

03

Codex·Claude에 MCP 설치

obulus는 검색·Open Call·메모리·수익 도구를, obulus-pay는 준비된 1회 결제만 제공합니다. 모든 URL에 결제할 수 있는 공식 Pay MCP는 기본 설치하지 않습니다.
