## 실패 게이트

아래 하나라도 해당하면 100점을 받을 수 없다.

- 핵심 결론이 표나 작은 UI 캡처 안에 묻힘
- 연결선이 노드 위를 지나가거나 다른 경로와 겹침
- 현재 Devnet을 mainnet escrow처럼 표현
- PageRank가 진실을 보증한다고 표현
- 현재 deterministic reflection을 Gemini 기반 고밀도 reflection처럼 표현
- 예시 수치를 실제 운영 실적으로 표현
- 발표 화면에 “몇 초”, “본편 n장”, 제작 체크리스트 같은 내부 메모 노출

## 새 HTML 덱의 100점 검수 순서

1. 본편 13장만 연속으로 보며 결론 문장과 다이어그램이 5초 안에 읽히는지 확인한다.
2. 1600×900 PNG로 모든 장을 렌더링하고 각 페이지를 개별 확인한다.
3. PDF로 다시 렌더링해 폰트 대체, 선 위치, 이미지 선명도, 페이지 수를 확인한다.
4. 다이어그램 D0~D7의 connector가 노드 뒤에 있고 교차가 없는지 확인한다.
5. `현재`, `정책`, `미래` 표현을 코드·문서와 대조한다.
6. 점수가 100점이 될 때까지 문장 밀도와 시각 위계를 반복 수정한다.
